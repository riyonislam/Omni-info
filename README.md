# Personal Automation & Utility Tools

A suite of personal automation scripts, workflows, and utility applications developed and maintained for private workflow management, scheduled publishing, and API integrations.

## Overview
These tools are built strictly for personal and authorized internal use to automate repetitive tasks across Google services and cloud workflows—without exposing credentials or data to external third parties.

### Covered Applications & Use Cases
- **Uploader Tool** — Scheduled video uploads and metadata management via YouTube Data API v3
- **Workflow & Productivity Tools** — Personal automation scripts integrating with Google Workspace APIs (such as Drive, Sheets, Gmail, or Calendar) when explicitly authorized

## Privacy Policy

*Last updated: November 2026*

We respect user privacy and strictly comply with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the **Limited Use** requirements.

### 1. Information We Access
- Access is requested solely via official OAuth 2.0 consent screens for the specific permissions (scopes) required by each tool.
- Only data necessary to execute the user-configured automation tasks (such as uploading videos, managing video metadata, or reading/writing authorized files) is accessed.

### 2. How Information Is Used
- All accessed data and API tokens are used **exclusively** to perform the automation actions triggered or scheduled by the account owner.
- User data obtained through Google APIs is **never** used to serve advertisements, build user profiles, or train third-party AI/ML models.

### 3. Data Storage & Security
- OAuth 2.0 credentials, Client Secrets, and Refresh Tokens are stored securely inside encrypted environment variables or private local configurations.
- No personal data, media files, analytics, or authentication tokens are sold, rented, shared, or transferred to any third parties.

### 4. Data Retention & Revoking Access
- No unnecessary personal data is retained beyond the active execution of automated tasks.
- You can view, manage, or revoke this application's access to any Google account at any time by visiting [Google Account Permissions](https://myaccount.google.com/permissions).
